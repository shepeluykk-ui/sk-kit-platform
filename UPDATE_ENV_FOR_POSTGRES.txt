║  Инструкция: Обновление .env для PostgreSQL                               ║
╚════════════════════════════════════════════════════════════════════════════╝

📝 ЧТО ДОБАВИТЬ В ФАЙЛ .env:

Откройте файл .env в корне проекта (D:\SK-KIT\.env) и добавьте или обновите строку:

    DATABASE_URL=postgresql://skkit_user:skkit_secure_password_change_in_production@localhost:6432/skkit_production

ВАЖНО: Используйте ИМЕННО эту строку подключения:
  ✓ Хост: localhost
  ✓ Порт: 6432 (pgbouncer, не 5432!)
  ✓ Пользователь: skkit_user
  ✓ Пароль: skkit_secure_password_change_in_production
  ✓ База данных: skkit_production

────────────────────────────────────────────────────────────────────────────

🚀 КАК ЗАПУСТИТЬ:

1. Убедитесь что .env обновлен (см. выше)

2. Запустите PowerShell в папке проекта (D:\SK-KIT)

3. Выполните команду:
   .\start-postgres-dev.ps1

4. Скрипт автоматически:
   ✓ Проверит Docker
   ✓ Запустит PostgreSQL + pgbouncer
   ✓ Установит npm зависимости (если нужно)
   ✓ Применит все 18 миграций БД
   ✓ Запустит приложение на http://localhost:3000

────────────────────────────────────────────────────────────────────────────

⚠️  ЕСЛИ ПОЛУЧИТЕ ОШИБКУ:

"Docker не установлен":
  → Скачайте Docker Desktop: https://www.docker.com/products/docker-desktop
  → Установите и перезагрузитесь
  → Запустите Docker Desktop
  → Вернитесь и запустите скрипт заново

"PostgreSQL не ответил за отведённое время":
  → Выполните: docker-compose logs postgres
  → Посмотрите логи ошибок

────────────────────────────────────────────────────────────────────────────

📊 РЕЗУЛЬТАТ:

После успешного запуска вы увидите:
  ✓ PostgreSQL запущен на localhost:5432
  ✓ pgbouncer работает на localhost:6432
  ✓ Все 18 миграций применены
  ✓ Приложение работает на http://localhost:3000

Приложение готово к использованию! 🎉
